## Copy rules (learned from user feedback)
- NEVER state Mobeeli's exact fee (no "5%"). Use "one low, flat rate" / "sellers keep more of every sale". Benefit-led, not comparison-led ("fraction of what big marketplaces charge" was rejected as forced). 0% promo + incumbent numbers are fine.
- Don't name Tokopedia/Shopee — "generalist marketplace".
- "Early Adaptors" spelling is intentional.
- ID copy: native casual-professional tone (naturalized 2026-07-22); user keeps EN loanwords in ID — "Join Waitlist", "Founders", "Launching" (not "Meluncur"), "join waitlist" verb; kickers "Masalah", "Menuju seluruh Nusantara"; investors ID says "mulai minat bergabung" / "setuju untuk join waitlist".
- No visionary/hype language, no emoji. Investor section invites a look, never says "raising".
- Footer: "Mobeeli — Jakarta, Indonesia" (no entity name until incorporation).
